# Car Dealership Project — лендинг автосервиса

Одностраничный лендинг автосервиса / автодилера, свёрстанный в стиле Tilda (секционные «vibe-блоки») на чистом HTML + CSS + vanilla JS. Всё содержимое находится в одном файле — `index.html`.

## Структура проекта

```
car-dealership-project/
└── index.html   # весь лендинг: секции, стили, скрипты
```

Каждая секция — самостоятельный `<section>` с собственным блоком `<style>` и (при необходимости) `<script>` внутри, как принято в блоках Tilda. Это позволяет копировать секции между страницами независимо.

## Секции страницы

1. **Навигация** — фиксированная шапка с логотипом, меню, телефоном и кнопкой; бургер-меню на мобильных.
2. **Hero** — главный экран с заголовком и CTA-кнопками.
3. **Преимущества / услуги** — сетка карточек.
4. **Портфолио / работы** — галерея с hover-эффектами.
5. **Процесс работы** — этапы обслуживания.
6. **Мастера** — карточки специалистов с фото, стажем и описанием.
7. **Форма записи** — контактная форма на тёмных полях.
8. **FAQ / инфо-секции** — дополнительные блоки.
9. **Футер** — контакты и навигация.

## Дизайн-токены

Палитра задаётся CSS-переменными в начале каждой секции:

```css
--acc:    #20C0AE;  /* акцентный цвет (бирюзовый/teal) */
--acc-hi: #47DCC8;  /* акцент при наведении */
--bg:     #16181B;  /* фон страницы (тёмный) */
--panel:  #1D2024;  /* фон карточек */
--line:   #2C3138;  /* цвет линий и рамок */
--text:   #F2F4F6;  /* основной текст */
--muted:  #A6ADB5;  /* приглушённый текст */
```

Чтобы сменить акцентный цвет на всём сайте, достаточно заменить значения `--acc` и `--acc-hi` (поиском и заменой по файлу).

## Технические детали

- **Без зависимостей** — только HTML, CSS и ванильный JavaScript.
- **Адаптивность** — медиа-запросы на брейкпоинтах 1100px, 700px, 520px.
- **Анимации появления** — секции с классом `is-anim` используют `data-reveal` и IntersectionObserver.
- **Доступность** — `aria-label`, поддержка `prefers-reduced-motion`, `focus-visible` для ссылок.
- **Изображения** — загружаются с CDN Tilda (`static.tildacdn.pub`) с `loading="lazy"`.

## Как запустить

Просто откройте `index.html` в браузере — сборка не требуется:

```powershell
Start-Process .\index.html
```

Или поднимите локальный сервер:

```powershell
python -m http.server 8000
# затем откройте http://localhost:8000
```
